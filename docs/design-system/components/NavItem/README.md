Mục điều hướng dọc (sidebar giảng viên, menu mobile), theo kiểu QLĐT/S-Link.

- Mục đang chọn: `aria-current="page"`, nền `ptit-red-100`, chữ `red-ink` đậm, vạch trái 3px `ptit-red-700`.
- Mục thường: chữ `ink`, hover `surface-sunken`.
- Icon lucide 18px nét 2px đứng trước nhãn. Nhãn là danh từ ngắn ("Khóa học", "Thống kê lớp").
