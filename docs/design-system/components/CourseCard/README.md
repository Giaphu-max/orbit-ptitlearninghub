Thẻ lớp/khóa học, cấu trúc như thẻ "Lớp tín chỉ" của S-Link để sinh viên quen mắt.

- Thứ tự: mã môn + chặng (`eyebrow`, `red-ink`) → tên môn (`title`, `ink-strong`) → 3 ô thống kê trên `surface-sunken` (buổi/bài, tài liệu, thảo luận) → "Tiếp theo" → thanh tiến độ → chân thẻ (tín chỉ + một hành động).
- Bo `radius-lg`, viền `line`, bóng `shadow-card`, nền `surface`.
- Lưới 4 cột desktop, khe `space-3`. Thẻ khóa đang học ở trang chủ Orbit được phóng to thành thẻ hero `radius-xl` có ảnh bìa.
- Người dùng cung cấp: mã môn, tên, số liệu, tiến độ, link hành động.
