Nhãn "Mới" và chip trạng thái, theo cách QLĐT/S-Link đánh dấu tin mới và LMS báo tiến độ.

- `po-badge--new`: nhãn vuông nhỏ đặt TRƯỚC dòng thông báo mới. Chữ "Mới" (không dùng "New").
- `po-chip--success`: hoàn thành / đúng tiến độ, luôn có ✓ hoặc chữ.
- `po-chip--brand`: trạng thái đang làm.
- `po-chip--gold`: phần thưởng, huy hiệu. Chỉ dùng cho thưởng.
- `po-chip--neutral`: sắp tới, chưa mở.
- Không dùng màu để phân biệt trạng thái một mình; chữ trong chip phải nói trạng thái.
