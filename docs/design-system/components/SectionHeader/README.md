Đầu mục kiểu S-Link/QLĐT: tiêu đề trái, link đỏ phải, kẻ mảnh dưới.

- Tiêu đề style `section`, màu `ink-strong`; link style `label`, màu `red-ink`, nội dung "Xem tất cả ›" hoặc "Xem tiếp ›".
- `po-eyebrow` (mono, HOA, `red-ink`) dùng cho nhãn chương trên trang chủ Orbit và mã môn.
- Đặt ở đầu mọi khối danh sách (thông báo, lớp, bài tập).
