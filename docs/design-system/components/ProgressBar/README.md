Thanh tiến độ cao 6px, track `surface-sunken`, số bên phải bằng `numeric`.

- Mặc định đỏ `ptit-red-600`: tiến độ khóa/chặng Orbit.
- `po-progress--info`: tiến độ buổi học kiểu S-Link (xanh `info`).
- `po-progress--done`: hoàn thành, kèm ✓.
- Người dùng cung cấp phần trăm (width) và nhãn số; luôn có `role="progressbar"` và `aria-valuenow`.
